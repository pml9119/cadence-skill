# Decisions

> ⚠️ **只有仓库没有权威决策源时才用这个文件。**
> 若已有（wayfinder 的 `map.md`、`docs/adr/`、别的账本）→ **不要创建它**，两份账本必然漂移。
> 改在 `docs/agents/flow.md` 里指明权威源在哪。

决策账本。**只增不删。**

**为什么要有这个**：每个 agent 都是 fresh context。没有账本，下一个 agent（或三个月后的你）会推翻已经定过的事，而且推翻得毫无察觉。

它同时也是回顾第 2 问的落点：这周定了什么，写在这里。

## 格式

```markdown
## YYYY-MM-DD · <一句话说清这个决策>

**背景**：当时为什么必须定这个
**决定**：定了什么
**放弃了什么**：被否掉的选项，以及为什么否掉
**可逆性**：容易改 / 难以改
```

**难以改的决策**同时应该落成 ADR，走 `/domain-modeling`。账本是时间线，ADR 是可被引用的规格。
