# Cadence · 保持活性与前置

[`SKILL.md`](SKILL.md) 推下来的参考之一。**一个周期之后、或换仓库搭环境时读。**

**它回答的是「这套东西会不会自己腐烂」。**

---

## 保持活性

**六样东西会腐烂，各有各的腐烂方式 —— 各配一个检查时机。**

| 东西 | 怎么腐烂 | 什么时候查 |
|---|---|---|
| **挂载点表** | 上面的 skill 改名 / 移动 / 废弃 | 三个月一次，看表头那个日期 |
| **导出工具表**（[`CHAT-INTAKE.md`](CHAT-INTAKE.md)） | 社区工具删库 / 官网下线 / 改协议 —— 2025-10 微信侧一次清掉三个 | 三个月一次，看表尾那个日期 |
| **`GLOSSARY.md`**（收原话的） | 同一个词长出第二个意思 | 每次 ③ 译；打架时跑 `/domain-modeling` |
| **决策账本** | 变成两份 | 每次新建文档时问一句「这算不算第二份账本」 |
| **`raw/` 的出处** | 源文件被移动 / 删除，行号失效 | 每次 ① 收；实查 5 条回原文件并落盘核验表 |
| **安装副本 (`~/.dsh/skills`)** | 工作区源码已改，安装副本未同步 | 每次修改 skill 源文件后立即执行全量镜像同步 |

**其余五条固定规矩**：

- 票是唯一真相源，看板是**视图**。**列的语义由票定义，工具跟着它走**
- **决策账本只增不删。** 只认 `docs/agents/flow.md` 里指明的**那一处**（wayfinder 的 `map.md` `Decisions so far` 段、仓库根 `DECISIONS.md`、或 `docs/adr/`）。`flow.md` 和 `direction.md` 只放指针
- **账本是防止下一个 agent（或三个月后的你）推翻已定决策的唯一机制** —— 它一旦变成两份，这个机制就失效了
- **收原话的落盘是原料，不是配置** —— `.intent/raw/` 进版本库，跟着代码一起走。**它和 `docs/agents/` 那两份配置的腐烂方式不同：配置会过期，原料只会丢**
- 踩到的每个坑 → 写回本 skill 或 `docs/agents/flow.md`

## 已知的薄弱点

**这三处会真的坏，坏的时候别怀疑自己。**

| 薄弱点 | 症状 | 怎么办 |
|---|---|---|
| **需求方弃权** | 「你决定吧」「都行」反复出现 | **停。** 触发「弃权即未定」：换成具体二选一或拿出草案，见 [`PROBING.md`](PROBING.md) 停手信号 |
| **导出件或乱文档读不出来** | 图片 / 语音占了大半；文档残缺、互相矛盾 | 别硬撑。**收口的判据就是为这个设的** —— 把缺失登记清楚，走 `/to-questionnaire` 让他补 |
| **没有可跑的命令** | 0 行代码，里程碑写不出「跑什么命令」 | 如实记「里程碑待定」，**把「造出第一条能跑的命令」排到候选清单第一位**。硬写一个假里程碑比不写更坏 |

## 前置

`/setup-matt-pocock-skills` 产出的 `docs/agents/issue-tracker.md` 必须已存在 —— `/code-review` 依赖它去 tracker 取 spec，D3 的「待批准」取数也依赖它。然后跑 `/setup-cadence` 搭出本层的仓库配置。

**收原话没有安装器，也不需要** —— `.intent/` 由它第一次跑时直接建，骨架在 [`templates/`](templates/)。**别为它写一个 `/setup-*`**：那会多一份要维护的东西，而它只有三个目录和几个文件。

**怎么验证这套东西还转得动**：一个周期后回头量三个数 —— 待验收最老年龄、返工次数、待批准最老等了几天。凡是量不出来的段落，就该拆掉。
